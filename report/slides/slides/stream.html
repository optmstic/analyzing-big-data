New months arrive every month, so I built a stream. The first delivery has the months of 2025, the second the months of 2026. The checkpoint remembers what was already read, so the second run only processes the new files. The control shows that the result is identical to a normal batch calculation. On serverless, the trigger availableNow processes what is waiting and stops.
