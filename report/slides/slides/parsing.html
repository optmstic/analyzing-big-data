The files are not tables. The first field packs four things: frequency, unit, measure and route. Here: annual, flights, passenger flights arriving at Faro from Vienna. Then one column per year, and a colon when there is no value. So I read them as text, and one function turns them into rows with split, posexplode and pivot. Each value is matched with the header of its own file, because the United Kingdom stopped reporting in 2019. Then six quality checks, all zero.
